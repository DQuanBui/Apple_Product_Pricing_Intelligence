# Apple Global Pricing Analysis
![](https://github.com/DQuanBui/apple_pricing_project/blob/main/apple.webp)
## Project Overview

The **Apple Global Pricing Analysis** project is an end-to-end data analytics and machine learning solution that explores how Apple product prices vary across countries, product categories, and technical specifications.

The project transforms raw pricing data into clear business insights through data cleaning, exploratory data analysis, interactive visualizations, predictive modeling, and a deployed Streamlit application.

This project demonstrates practical skills in Python, data analysis, machine learning, dashboard development, business insight generation, and cloud deployment.

## Live Application

Explore the interactive Streamlit application:

**Website:** https://applepricing.streamlit.app/

## Project Objectives

The project was developed to answer key pricing questions, including:

- Which countries have the highest and lowest Apple product prices?
- Which product categories show the greatest international price differences?
- How do storage, memory, product type, and other specifications affect price?
- Which markets offer stronger relative value for Apple products?
- What features are the strongest predictors of product price?
- Can machine learning accurately estimate Apple product prices?

## Tools and Technologies

- **Python** — data analysis and application development
- **Pandas and NumPy** — data cleaning, transformation, and analysis
- **Matplotlib and Seaborn** — statistical data visualization
- **Plotly** — interactive dashboard charts
- **Scikit-learn** — preprocessing, machine learning, and model evaluation

## Data Preparation

The dataset was prepared through a structured data-quality process:

- Checked missing values and duplicate records
- Standardized column names and data types
- Removed unnecessary currency columns
- Retained a consistent currency for international comparison
- Cleaned price and product specification fields
- Reviewed invalid values and potential outliers
- Created analysis-ready features for visualization and modeling

## Analysis Results

The analysis identified meaningful differences in Apple pricing across international markets.

Key findings include:

- Apple product prices vary significantly between countries.
- Some markets consistently show higher pricing premiums.
- Product category, storage, memory, model type, and country are important price drivers.
- Premium product configurations generally have greater price variation.
- Country-level comparisons reveal markets with stronger relative value.
- Machine learning can estimate Apple product prices using product and market characteristics.

## Machine Learning

Multiple regression models were evaluated to predict Apple product prices.

The modeling workflow included:
- Separating numerical and categorical features
- Handling missing values
- Encoding categorical variables
- Splitting the dataset into training and testing sets
- Training and comparing regression models
- Evaluating performance using R², MAE, and RMSE
- Integrating the final model into the Streamlit application

The prediction tool allows users to select product characteristics and receive an estimated Apple product price.

## Application Features

The Streamlit application allows users to:

- View key pricing metrics
- Filter data by country and product category
- Compare average prices across markets
- Explore interactive charts and rankings
- Analyze price distributions
- Review important pricing factors
- Evaluate machine learning performance
- Generate product price predictions
